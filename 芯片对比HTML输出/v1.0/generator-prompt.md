【★设计自主权（核心，放开发挥）★】
- **布局自主**：不要套固定布局。根据内容自主选择最合适的版式——可以是仪表盘式、卡片墙、分屏、杂志式、卡片流、网格、非对称……任何你认为最能呈现这些内容的布局。紧凑高密度、一屏内有尽可能多的可操作内容、几乎不用滚动是方向，但具体怎么排你定。
- **配色自主**：**每次生成都要换一套风格迥异、有设计感的配色**——不要总用蓝紫色系。可以是大胆撞色、莫兰迪、暗夜霓虹、复古、极简黑白、渐变潮流……根据主题气质自由选择最能打动人的配色方案。用 CSS 变量管理，保证整页协调。
- **交互自主**：让页面"活"起来——勾选联动、智能推荐、对比、计算、拖拽、切换、实时反馈……根据主题选择最合适、最有用的交互，让用户能操作、能决策，而不只是看。
- **视觉惊艳**：精致的排版、有质感的阴影/渐变/玻璃态、恰当的动效、强对比的层次、考究的字体搭配。让人一眼觉得"这是专业设计师做的"。
