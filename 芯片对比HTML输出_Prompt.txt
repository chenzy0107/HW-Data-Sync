## 角色

资深前端工程师 + 数据可视化专家。输出**一个完整、可独立运行的单 HTML 文件**——多实体 × 多维度对比仪表盘。

## ⛔ 硬性约束

1. 单文件，HTML/CSS/JS/数据全内联，不拆分、不外链本地文件。
2. 纯原生 HTML+CSS+JS（ES2020），**禁止**任何框架/库/构建步骤（React/Vue/jQuery/Tailwind/npm 等）。
3. **唯一外部依赖**为 ECharts（按第五章 CDN 策略），**不得**引入其它任何库。本工具为纯展示用途，**不做导出、不做复制**。
4. 除 ECharts CDN 外不请求任何在线资源（无在线字体/图片/SDK）。禁止 `eval`、`Function`、`innerHTML` 拼接用户输入。
5. 所有 ECharts/Canvas 操作 try-catch；兼容近 2 年主流浏览器。
6. **输出的 HTML 代码内禁止任何解释性内容**：不得包含注释（含 HTML `<!-- -->`、CSS `/* */`、JS `//` 与 `/* */`）、不得有说明性文字、不得在代码中遗留 TODO/占位说明。函数与变量命名应自解释，代替注释。代码块之外（HTML 文件首尾外）可有简短使用说明，但**代码内部必须干净零注释**。

## 一、产品目标

多实体 × 多维度对比仪表盘：实体勾选（含搜索）、维度勾选 + 权重设置（实时联动）、**只生成并展示智能匹配的 3 个图表**（共 7 种候选，未选中者不生成不展示）、场景化推荐（推荐 + 备选 + 理由）、主题随实体变化（固定浅色风格）、离线降级 + 重试恢复、配置 localStorage 持久化、群体洞察与双实体对比。代码须健壮、可解释、可访问、视觉精致、性能克制。本工具为**纯展示**用途，不做导出、不做复制。

## 三、功能与交互

### 3.1 控制面板
- **实体勾选**：复选框 + 全选；>8 个时显示搜索框（按 name/desc 模糊匹配）。**<2 个不对比**，图表区给空状态提示。
- **维度勾选**：复选框 + 全选；>6 个时折叠分组。**0 个不计算综合分**。
- **权重**：每勾选维度一个滑块(0–100)+数字输入，旁注占总权重百分比。**只有"勾选且权重>0"参与综合分**。滑块 150ms 防抖。
- **场景**：按钮组，点击套用 `weights`（涉及维度自动勾选、未涉及权重置 0 但不取消勾选），高亮当前场景；手改权重后标"自定义"。
- **外观**：主题下拉（仅切换实体风格包的配色/背景，固定浅色风格，**不提供深色模式**）。
- **按钮**：重置 / 双实体对比。

### 3.2 推荐区
- 综合分降序，第 1 名"⭐ 最佳推荐"，第 2 名"📌 备选"（`showRunnerUp`）。
- **多句式理由**：主因句（该实体 vs 其他实体归一化分差最大的 1–2 维度，配维度优势词）+ 取舍句（最弱维度 vs 对手）+ 场景契合句（场景权重最高维度）。备选卡说明与首选的取舍。
- **敏感度提示**：拖权重致前 2 名互换时，瞬时显示"推荐从 X 切换为 Y"，2s 消失。
- **群体洞察卡**：自动 2–3 条文字——整体最强/最弱维度、分化最大的维度、最均衡/最偏科的实体。
- 切换场景/权重 → 推荐随之变化，**不同场景推荐不同实体**。

### 3.3 图表（只生成并展示智能匹配的 3 个，其余图表不渲染、不提供入口）

**只渲染 `pickCharts(entities, dims, scenario)` 选出的 3 个图表**，其余候选图表**一律不生成、不展示、不提供"更多/添加"入口**。图表区固定 3 个槽位，状态变化时由 `pickCharts` 重新计算并替换槽位内容，平滑过渡。

候选池（共 7 种，仅用于 `pickCharts` 内部挑选，不会被全部渲染）：

| 图表 | 用途 | 适用条件 | 低/高维度策略 |
|------|------|----------|--------------|
| 雷达图 | 能力轮廓对比 | 维度≥3 | <3 维→不选；>10 维→权重前 8 |
| 分组柱状图 | 维度数值对比 | 维度 1–6 | 维度过多时拥挤，>6 优先热力图 |
| 热力图 | 实体×维度矩阵 | 维度≥2 且实体≥3 | 单维度→不选 |
| 加权得分横向条形图 | 综合分排名 | 始终适合 | 第 1 名高亮 |
| 得分构成堆叠条形图 ⭐ | 各维度对总分贡献 | 维度≥2 | 独立于排名图 |
| 散点图(气泡) | 双维度象限定位 | 维度≥2 | X=权重最高/Y=第二/气泡=第三，不足按 key 字母序，副标题标注 |
| 折线图(堆叠) | 跨维度趋势 | 维度≥3 且有序 | 维度有序时 |

**`pickCharts` 匹配规则（按优先级，选满 3 个即止）：**

1. **综合分排名图必选其一**：优先「加权得分横向条形图」（始终适合）。它回答"谁总分最高"。
2. **根据维度数选"轮廓对比图"**：维度≥3 选「雷达图」（最直观的能力轮廓）；维度 1–2 选「分组柱状图」。
3. **根据场景权重集中度选"第 3 图"**：
   - 若场景权重明显集中于 2 个维度（最高两维权重占比 ≥55%），选「散点图」呈现该两维度的象限定位（性价比/定位分析）。
   - 否则选「得分构成堆叠条形图」呈现各维度对总分的贡献（可解释性，回答"分从哪来"）。
4. **候选不足 3 个的兜底**：按"热力图 → 分组柱状图 → 折线图"顺序补足至 3 个；若总可用图表 <3（如维度=1、实体=2 的极简场景），则按实际可用数量渲染，不强制凑数，空槽位显示"当前数据不足以展示更多图表"。

匹配结果随状态实时变化：用户勾选实体/维度、切场景、调权重后，`pickCharts` 重新计算，自动替换不合适的图表（如维度从 2 增到 3 时，柱状图自动换成雷达图）。

- **群体基准线**：雷达图叠加群体平均轮廓（灰虚线），柱状图叠加平均 markLine。
- **得分构成图**：每实体一行，总长=综合分，分段=`归一化分×权重/总权重`，hover "维度：贡献 X 分（Y%）"。
- **大数据保护**：选中实体 >12 时雷达/散点/折线仅渲染前 12 名并提示。
- 防抖 150ms 重绘；`ResizeObserver` 触发 `resize()`。

### 3.4 双实体对比
浮层选两实体，左右并列各维度原始分/归一化分/差值，差值绿(优势)/红(劣势)高亮，底部"X 在 N 项优于 Y，主要差距在{维度}"。

### 3.5 明细表
行=实体，列=原始分/归一化分/加权贡献/综合分/排名；推荐列标 ⭐推荐(第1)/✓可选/✕不推荐(末位)，分数渐变着色；表头可排序；行点击 → ECharts `highlight` 联动；**行可展开显示该实体完整计算过程**。

### 3.6 空状态文案（统一）
- 实体<2：「📋 请至少选择 **2 个实体**进行对比（当前 N 个）」
- 维度=0：「📐 请至少选择 **1 个维度**」
- 权重全 0：「⚖️ 所选维度权重均为 0」
- 双实体相同：「🔀 请选择两个不同实体」
- 离线：「⚠ 离线降级模式，图表简化版，联网后点【🔄 重试加载】恢复」
- 截断：「🔮 仅显示综合分前 12 名（共 N 个）」

- 卡片：`background:var(--panel-bg); backdrop-filter:blur(var(--blur)); border:1px solid var(--border); border-radius:var(--radius-lg); box-shadow:var(--shadow-card);` 推荐卡加 `--shadow-glow`。
- 字号阶梯：标题 22/700、副标 16/600、正文 14/400、辅助 12；行高 1.5–1.6。间距 8 的倍数。
- 微交互：hover `translateY(-2px)` + 阴影加深，`.25s cubic-bezier(.4,0,.2,1)`；按钮 active `scale(.97)`。自定义美观 range 滑块。body 叠加径向光晕伪元素。
- **响应式断点**：≥1200px 左右双栏（面板 320px+主区）；768–1199px 上下堆叠；<768px 面板折叠抽屉、图表单列。
- **动效预算**：首屏可交互<1s，单图切换<300ms，ECharts `animationDuration:600 cubicOut`，**禁持续循环动画**。
- **可访问性**：键盘可达 + focus 可见轮廓(`outline:2px solid var(--accent)`)，图表 `aria-label`，图标按钮 `title`，对比度 WCAG AA，不只靠颜色区分。`prefers-reduced-motion` 下 `animation:false`/transition 置 0.01ms。
- **打印**(`@media print`)：白底深字、去模糊阴影、展开折叠区、页眉含场景+实体清单。

## 五、离线支持

1. **多 CDN 降级**：`loadScriptWithFallback(urls)` 按序加载，`onerror` 试下一个（完整 URL 勿改）：
   ```js
   const ECHARTS_CDN = [
     'https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js',
     'https://unpkg.com/echarts@5.5.1/dist/echarts.min.js',
     'https://cdnjs.cloudflare.com/ajax/libs/echarts/5.5.1/echarts.min.js'
   ];
   ```
2. **离线兜底**：`typeof echarts==='undefined'` 时 `OfflineRenderer`（纯 Canvas 2D）渲染 **雷达/柱状/加权条形** 3 类核心图，其余占位"🔌 联网后查看"，顶部提示条含"🔄 重试加载"。
3. **重试恢复**：点重试重新加载；成功后自动隐藏提示、销毁离线 Canvas、用 ECharts 重绘全部图表，无需刷新。
4. **页面本身完全不依赖网络**：综合评分/推荐/明细/洞察/双实体对比离线必须完整可用。本地部署：下载 `echarts.min.js` 到同目录，`ECHARTS_CDN` 首位改 `'./echarts.min.js'`。

## 六、算法与扩展

### 6.1 容错与归一化
```js
function safeScore(e, k, d){ const v=e.scores?.[k]; return (typeof v!=='number'||Number.isNaN(v))?d.min:v; }
function normalizeScore(d, raw){
  if (d.max===d.min) return 50;
  const r=(raw-d.min)/(d.max-d.min);
  return Math.max(0,Math.min(1, d.higherBetter?r:(1-r)))*100;
}
```

### 6.2 加权综合分 + 短板惩罚
```js
function computeWeighted(e, activeDims, weights, pen){
  let total=0, wsum=0, minNorm=100, contribs=[];
  for (const d of activeDims){
    const w=weights[d.key]||0; if(w<=0) continue;
    const n=normalizeScore(d, safeScore(e,d.key,d));
    total+=n*w; wsum+=w; if(n<minNorm)minNorm=n;
    contribs.push({key:d.key,name:d.name,contrib:n*w/wsum,norm:n});
  }
  if(wsum<=0) return {score:0,avg:0,minNorm:0,contribs:[]};
  const avg=total/wsum;
  const p = pen>0 ? (1-pen*(1-minNorm/100)) : 1;
  return {score:avg*p, avg, minNorm, contribs};
}
```
降序排名，同分按 `avg` 再按 `id`。维度→优势词映射（未知维度回退"突出"）：`{perf:'强劲',price:'实惠',ux:'流畅',battery:'持久',design:'出众'}`。

### 6.3 扩展指南（HTML 顶部可折叠"📖 使用说明"面板须含）
- 加实体：`entities` 追加，`scores` 覆盖所有维度 key（缺失按 min 兜底）。
- 加维度：`dimensions` 追加 + 给每个实体补该 key。
- 加场景：`scenarios` 追加，`weights` 的 key 须对应已有维度。
- 加主题：`themes` 追加（`bg` 须合法 CSS），改 `themeKey`。
- 离线：`ECHARTS_CDN` 首位改 `'./echarts.min.js'`。

## 七、持久化与生命周期

- **localStorage**：勾选/权重/场景/主题存 `cmp_state_v{CONFIG.version}`；刷新恢复。读取 try-catch，损坏或 `version` 不匹配则丢弃旧状态恢复默认。
- **首屏骨架屏**：图表区先占位灰色脉冲块，就绪后淡入。
- **ECharts 实例管理**（防泄漏）：`chartRegistry`(Map) 统一管理，重渲染前 `dispose()` 旧实例，`beforeunload` 清理全部。
- **统一主题基底**（所有图表，固定浅色）：`backgroundColor:'transparent'`，文字 `#475569`，tooltip 浅色半透明+blur，坐标轴文字 `#475569`、分割线 `rgba(15,23,42,.12)`；系列色取 `entityColors`。
