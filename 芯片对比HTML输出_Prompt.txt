## 三、功能与交互

### 3.1 控制面板（左侧粘性侧栏，见 4.1 布局架构）
- **实体勾选**：复选框 + 全选。**<2 个不对比**，图表区给空状态提示。
- **维度（勾选 + 权重合一）**：每个维度占一行，左侧复选框 + 维度名，右侧权重滑块(0–100)+数字输入，旁注占总权重百分比。顶部"全选"控制勾选。>6 个时折叠分组。**只有"勾选且权重>0"参与综合分**；**0 个勾选不计算综合分**。滑块 150ms 防抖。
- **场景**：按钮组，点击套用 `weights`（涉及维度自动勾选、未涉及权重置 0 但不取消勾选），高亮当前场景；手改权重后标"自定义"。
- **按钮**：重置（位于顶部导航栏右侧）。
- **移动端入口**：<1200px 时控制面板折叠为顶部抽屉，由顶部导航栏左侧的「⚙ 筛选」按钮触发展开/收起（默认收起，展开时覆盖主区上层）。

### 3.2 推荐区
- 综合分降序，第 1 名"⭐ 最佳推荐"，第 2 名"📌 备选"（`showRunnerUp`）。
- **多句式理由**：主因句（该实体 vs 其他实体归一化分差最大的 1–2 维度，配维度优势词）+ 取舍句（最弱维度 vs 对手）+ 场景契合句（场景权重最高维度）。备选卡说明与首选的取舍。
- **敏感度提示**：拖权重致前 2 名互换时，瞬时显示"推荐从 X 切换为 Y"，2s 消失。
- **群体洞察卡**：自动 2–3 条文字——整体最强/最弱维度、分化最大的维度、最均衡/最偏科的实体。
- 切换场景/权重 → 推荐随之变化，**不同场景推荐不同实体**。

### 3.3 图表（只生成并展示智能匹配的 3 个，其余图表不渲染、不提供入口）

**只渲染 `pickCharts(entities, dims, scenario)` 选出的 3 个图表**，其余候选图表**一律不生成、不展示、不提供"更多/添加"入口**。图表区固定 3 个槽位，状态变化时由 `pickCharts` 重新计算并替换槽位内容，平滑过渡。

候选池（共 7 种，仅用于 `pickCharts` 内部挑选，不会被全部渲染）：

| 图表 | 用途 | 适用条件 | 低/高维度策略 |
|------|------|----------|--------------|
| 雷达图 | 能力轮廓对比 | 维度≥3 | <3 维→不选；>10 维→权重前 8 |
| 分组柱状图 | 维度数值对比 | 维度 1–6 | 维度过多时拥挤，>6 优先热力图 |
| 热力图 | 实体×维度矩阵 | 维度≥2 且实体≥3 | 单维度→不选 |
| 加权得分横向条形图 | 综合分排名 | 始终适合 | 第 1 名高亮 |
| 得分构成堆叠条形图 ⭐ | 各维度对总分贡献 | 维度≥2 | 独立于排名图 |
| 散点图(气泡) | 双维度象限定位 | 维度≥2 | X=权重最高/Y=第二/气泡=第三，不足按 key 字母序，副标题标注 |
| 折线图(堆叠) | 跨维度趋势 | 维度≥4（兜底候选，优先级最低） | 维度≥4 时作为兜底 |

**`pickCharts` 匹配规则（按优先级，选满 3 个即止）：**

1. **综合分排名图必选其一**：优先「加权得分横向条形图」（始终适合）。它回答"谁总分最高"。
2. **根据维度数选"轮廓对比图"**：维度≥3 选「雷达图」（最直观的能力轮廓）；维度≥2 选「分组柱状图」；**维度=1 时跳过本步**（因柱状图与规则1 的排名图信息重复），改由规则3/4 补足第 2 图。
3. **根据场景权重集中度选"第 3 图"**：
   - 若场景权重明显集中于 2 个维度（最高两维权重占比 ≥55%），选「散点图」呈现该两维度的象限定位（性价比/定位分析）。
   - 否则选「得分构成堆叠条形图」呈现各维度对总分的贡献（可解释性，回答"分从哪来"）。
4. **候选不足 3 个的兜底**：从**当前实际满足适用条件**的剩余候选中，按"热力图 → 分组柱状图 → 折线图 → 散点图 → 得分构成图"顺序补足至 3 个（跳过不满足条件的，如实体<3 时跳过热力图、维度<4 时跳过折线图）；若满足条件的图表总数 <3（如维度=1、实体=2 的极简场景），则按实际可用数量渲染，不强制凑数，空槽位显示"当前数据不足以展示更多图表"。

匹配结果随状态实时变化：用户勾选实体/维度、切场景、调权重后，`pickCharts` 重新计算，自动替换不合适的图表（如维度从 2 增到 3 时，柱状图自动换成雷达图）。

- **群体基准线**：雷达图叠加群体平均轮廓（灰虚线），柱状图叠加平均 markLine。
- **得分构成图**：每实体一行，总长=综合分，分段=`归一化分×权重/总权重`，hover "维度：贡献 X 分（Y%）"。
- **大数据保护**：选中实体 >12 时，雷达/散点/折线仅渲染**综合分前 12 名**（按当前加权综合分降序，与排名图基准一致），并显示截断提示条（见 3.5 第4条）。
- 防抖 150ms 重绘；`ResizeObserver` 触发 `resize()`。

### 3.4 明细表
行=实体，列=原始分/归一化分/加权贡献/综合分/排名；推荐列标记规则（与 3.2 推荐区一致，按优先级）：第 1 名 ⭐推荐；第 2 名 📌备选（若 `showRunnerUp`）；**第 3 名至倒数第 2 名** ✓可选；**仅当实体≥4 时**，末位标 ✕不推荐（实体=2~3 时无"不推荐"，避免备选与不推荐冲突）。分数渐变着色；表头可排序；行点击 → 对当前已渲染的图表触发 ECharts `highlight` 联动高亮该实体系列（若该实体因截断未出现在某图表中，则该图忽略，不报错）；**行可展开显示该实体完整计算过程**。

### 3.5 空状态文案（统一）
空状态判定**按优先级**（高→低），命中即展示对应文案并暂停图表渲染：
1. 实体<2：「📋 请至少选择 **2 个实体**进行对比（当前 N 个）」
2. 维度=0：「📐 请至少选择 **1 个维度**」
3. 权重全 0（已勾选维度权重均为 0）：「⚖️ 所选维度权重均为 0，请调高至少一个维度」
4. 截断（实体>12）：「🔮 仅显示综合分前 12 名（共 N 个）」（此为提示条，不阻塞渲染）
5. 离线：「⚠ 离线降级模式，图表简化版，联网后点【🔄 重试加载】恢复」（顶部提示条）

## 四、视觉规格

**风格随实体类型（`CONFIG.domain`）自动适配**：页面加载时读取 `domain`，从 `STYLES` 取对应风格包，把 `primary`/`accent`/`bg` 注入 `:root` CSS 变量。**声明式自动套用，无运行时切换 UI**。所有风格包均为浅色基调，仅色调/氛围不同。

```css
:root{
  --primary:#3b82f6; --accent:#06b6d4;          /* 由 CONFIG.domain 自动覆盖 */
  --bg-image:linear-gradient(135deg,#eff6ff 0%,#e0e7ff 50%,#f0f9ff 100%);
  --panel-bg:rgba(255,255,255,.75);
  --text:#1e293b; --text-dim:#475569; --text-faint:#94a3b8;
  --border:rgba(15,23,42,.12);
  --radius-lg:20px; --radius-md:14px; --radius-sm:8px;
  --shadow-card:0 8px 32px rgba(15,23,42,.12); --shadow-glow:0 0 24px rgba(59,130,246,.18);
  --blur:12px; --gap:20px;
  --font-stack:'-apple-system',BlinkMacSystemFont,'Segoe UI','PingFang SC','Microsoft YaHei',sans-serif;
}
```

`applyStyle()`（启动时调用一次）：`const s = STYLES[domain] || STYLES.generic;` 将 `s.primary→--primary`、`s.accent→--accent`、`s.bg→--bg-image` 写入 `:root`，`--shadow-glow` 用 `s.primary` 重新生成。未知 `domain` 回退 `generic`。

**风格示例**（均浅色）：
- `tech` 科技风（芯片/数码）：蓝青调，冷静理性
- `nature` 自然风（植物/生态）：绿调，清新生机
- `warm` 暖色风（食品/家居）：橙黄调，温暖活力
- `business` 商务风（金融/企业）：青蓝调，沉稳专业
- `elegant` 雅致风（艺术/美妆）：紫调，精致优雅
- `generic` 通用：靛青调，中性

### 4.1 布局架构（现代化栅格，必须按此分区，禁止上下堆叠块状老式排版）

采用 **CSS Grid + Flexbox** 的"仪表盘式"布局，而非传统从上到下的标题+方块。整体三段式：

```
┌─────────────────────────────────────────────────────────┐
│  顶部导航栏（粘性 sticky）：标题 + domain 风格徽标 + 重置  │  高 64px
├──────────────┬──────────────────────────────────────────┤
│              │  ① 推荐区（横排卡片：首选 + 备选 + 群体洞察）│
│  左侧控制面板 │  ──────────────────────────────────────  │
│  （粘性侧栏） │  ② 图表区（3 个图表，2+1 网格）            │
│  宽 300px     │  ──────────────────────────────────────  │
│  独立滚动     │  ③ 明细表（全宽）                          │
└──────────────┴──────────────────────────────────────────┘
```

**关键现代化规则**：

1. **左右双栏**（桌面 ≥1200px）：左栏控制面板（宽 300px，`position:sticky; top:80px; max-height:calc(100vh-96px); overflow-y:auto;`，独立滚动不与主区耦合）；右栏主内容区。**严禁**所有控件从上到下平铺成一长条。
2. **推荐区横排卡片**：首选/备选/群体洞察**横向并排**（`display:flex; gap:16px; align-items:stretch;`），首选卡 `flex:1.4` 加宽 + `--shadow-glow` + 渐变描边突出，其余等宽。**禁止**纵向堆叠。（卡片内容见 3.2）
3. **图表区自适应网格**：图表满 3 个时用 `display:grid; grid-template-columns:repeat(2,1fr); gap:20px;`，前两个并排、第三个跨两列（`grid-column:1/-1`）；仅 2 个时双列并排；仅 1 个时单列居中（`max-width` 限制避免过宽）。每张图卡固定最小高度（如 360px），内部 ECharts 居中填充。避免三个等宽挤一行显得呆板。
4. **卡片即容器**：每个分区都是独立的毛玻璃卡片（圆角 20px、阴影、半透明白底），卡片之间靠 `gap` 留白分隔，**不用**硬边框分割区块。卡片内 padding 24px。
5. **视觉层级靠间距与字重**，非边框线：区块之间用 24–32px 间距区隔，**区块小标题**用 18px/700 + 左侧 4px 主题色竖条装饰（`border-left`），正文 14px/400。避免用 `<hr>` 或粗边框划区。（页面主标题 22px 见 4.2）
6. **顶部导航栏**：`position:sticky; top:0; z-index:50;` 半透明毛玻璃 + 底部细分割线，含：页面标题（左）、当前 domain 风格徽标（中）、重置按钮（右）；<1200px 时左侧标题旁增加「⚙ 筛选」按钮用于展开/收起控制面板抽屉。
7. **控制面板内部**：用小标题分组（"实体"/"维度"/"场景"），每组间 20px 间距，组内控件紧凑。维度行（勾选+滑块）用浅灰圆角内框（`background:rgba(15,23,42,.04); border-radius:12px; padding:10px 12px;`）包裹，形成"行卡片"质感。
8. **响应式**：768–1199px 双栏变单栏（控制面板移到顶部折叠抽屉，由导航栏「⚙ 筛选」按钮触发展开/收起）；<768px 全部单列，图表单列堆叠，推荐卡纵向堆叠。

### 4.2 材质与细节

- 卡片：`background:var(--panel-bg); backdrop-filter:blur(var(--blur)); border:1px solid var(--border); border-radius:var(--radius-lg); box-shadow:var(--shadow-card);` 推荐首选卡加 `--shadow-glow` + 1px 渐变描边（`border-image` 或双层 box-shadow）。
- 字号阶梯：**页面主标题** 22/700、**区块小标题** 18/700、副标 16/600、正文 14/400、辅助 12；行高 1.5–1.6。间距严格用 8 的倍数（8/12/16/20/24/32）。
- 微交互：hover `translateY(-2px)` + 阴影加深，`.25s cubic-bezier(.4,0,.2,1)`；按钮 active `scale(.97)`；卡片入场用 `opacity:0→1 + translateY(8px→0)` 错落淡入（`animation-delay` 按序 60ms 递增）。自定义美观 range 滑块（轨道主题色填充 + 圆形拇指 + hover 放大）。body 叠加径向光晕伪元素（主题色 6% 透明）增加层次。
- 数字强调：综合分等关键数字用更大字号（28–32px）/700 + 主题色，形成视觉锚点。
- **动效预算**：首屏可交互<1s，单图切换<300ms，ECharts `animationDuration:600 cubicOut`，**禁持续循环动画**。
- **可访问性**：键盘可达 + focus 可见轮廓(`outline:2px solid var(--accent)`)，图表 `aria-label`，图标按钮 `title`，对比度 WCAG AA，不只靠颜色区分。`prefers-reduced-motion` 下 `animation:false`/transition 置 0.01ms。
- **打印**(`@media print`)：白底深字、去模糊阴影、展开折叠区、页眉含场景+实体清单。

## 五、离线支持

1. **多 CDN 降级**：`loadScriptWithFallback(urls)` 按序加载，`onerror` 试下一个（完整 URL 勿改）：
   ```js
   const ECHARTS_CDN = [
     'https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js',
     'https://unpkg.com/echarts@5.5.1/dist/echarts.min.js',
     'https://cdnjs.cloudflare.com/ajax/libs/echarts/5.5.1/echarts.min.js'
   ];
   ```
2. **离线兜底**：`typeof echarts==='undefined'` 时 `OfflineRenderer`（纯 Canvas 2D）仅能渲染 **雷达图/分组柱状图/加权得分横向条形图** 3 类。此时对 pickCharts 选出的 3 个图表做**能力映射**：属于这 3 类的直接 Canvas 绘制；不属于的（得分构成图/散点图/热力图/折线图）**降级为加权得分条形图**（保证离线下仍有排名可视化），并在图卡角标注"🔌 简化版"。顶部提示条含"🔄 重试加载"。
3. **重试恢复**：点重试重新加载；成功后自动隐藏提示、销毁离线 Canvas、用 ECharts 重绘全部图表，无需刷新。
4. **页面本身完全不依赖网络**：综合评分/推荐/明细/洞察离线必须完整可用。本地部署：下载 `echarts.min.js` 到同目录，`ECHARTS_CDN` 首位改 `'./echarts.min.js'`。

## 六、算法与扩展

### 6.1 容错与归一化
```js
function safeScore(e, k, d){ const v=e.scores?.[k]; return (typeof v!=='number'||Number.isNaN(v))?d.min:v; }
function normalizeScore(d, raw){
  if (d.max===d.min) return 50;
  const r=(raw-d.min)/(d.max-d.min);
  return Math.max(0,Math.min(1, d.higherBetter?r:(1-r)))*100;
}
```

### 6.2 加权综合分 + 短板惩罚
```js
function computeWeighted(e, activeDims, weights, pen){
  let total=0, wsum=0, minNorm=100;
  const raw=[];
  for (const d of activeDims){
    const w=weights[d.key]||0; if(w<=0) continue;
    const n=normalizeScore(d, safeScore(e,d.key,d));
    total+=n*w; wsum+=w; if(n<minNorm)minNorm=n;
    raw.push({key:d.key,name:d.name,norm:n,w});
  }
  if(wsum<=0) return {score:0,avg:0,minNorm:0,contribs:[]};
  const avg=total/wsum;
  const p = pen>0 ? (1-pen*(1-minNorm/100)) : 1;
  const contribs=raw.map(r=>({key:r.key,name:r.name,contrib:r.norm*r.w/wsum,norm:r.norm}));
  return {score:avg*p, avg, minNorm, contribs};
}
```
> 注意：贡献占比必须用**最终的 wsum** 统一计算，不能在循环内用尚未累加完成的中间 wsum，否则各维度贡献占比不一致、求和≠综合分。降序排名，同分按 `avg` 再按 `id`。维度→优势词映射（未知维度回退"突出"）：`{perf:'强劲',price:'实惠',ux:'流畅',battery:'持久',design:'出众'}`。

### 6.3 扩展指南（HTML 顶部可折叠"📖 使用说明"面板须含）
- 加实体：`entities` 追加，`scores` 覆盖所有维度 key（缺失按 min 兜底）。
- 加维度：`dimensions` 追加 + 给每个实体补该 key。
- 加场景：`scenarios` 追加，`weights` 的 key 须对应已有维度。
- 换风格：在 `STYLES` 加一个风格包（浅色基调），把 `CONFIG.domain` 改成对应 key 即可自动套用（如 `nature`→植物自然风）。未知 domain 回退 `generic`。
- 离线：`ECHARTS_CDN` 首位改 `'./echarts.min.js'`。

## 七、持久化与生命周期

- **localStorage**：勾选实体/维度、**各维度权重数值**（无论是否来自场景或手动调整）、当前场景标识（若用户手改权重则存 `'custom'`）存 `cmp_state_v{CONFIG.version}`；刷新后按权重数值精确恢复，并据其是否匹配某场景来恢复场景高亮或显示"自定义"。读取 try-catch，损坏或 `version` 不匹配则丢弃旧状态恢复默认。
- **首屏骨架屏**：图表区先占位灰色脉冲块，就绪后淡入。
- **ECharts 实例管理**（防泄漏）：`chartRegistry`(Map) 统一管理，重渲染前 `dispose()` 旧实例，`beforeunload` 清理全部。
- **统一图表配色**（固定浅色，跟随 `domain`）：`backgroundColor:'transparent'`，图表文字/坐标轴 `#475569`、分割线 `rgba(15,23,42,.12)`；tooltip 用浅色半透明背景 `rgba(255,255,255,.92)` + `backdrop-filter:blur(8px)`，**tooltip 文字色 `#1e293b`**（深字保证对比度）；实体系列色取 `entityColors`，主题强调色用 `STYLES[domain].primary/accent`（与页面 CSS 变量一致）。
